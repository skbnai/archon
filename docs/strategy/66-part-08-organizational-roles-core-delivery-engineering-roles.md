# Core AI Delivery & Engineering Roles

The core delivery and engineering roles form the backbone of enterprise AI capability. These roles span from specialized AI engineers to platform engineers, each with distinct skill sets and career progression paths.

## Senior AI Architect

**Level:** Senior IC / Manager | **Mentors:** Junior architects, leads architecture reviews

**Responsibilities:** Design end-to-end AI systems; conduct architecture reviews for high-risk AI deployments; establish AI architecture patterns and standards; mentor junior architects; lead cross-team architecture working groups; assess emerging AI technologies; ensure scalability, security, and governance in AI designs.

**Skills Required:** Deep technical knowledge (ML, GenAI, Agentic AI architectures); systems design and scalability; security architecture; governance frameworks; communication with senior leadership; vendor evaluation.

## ML/AI Engineer (Traditional ML Track)

**Level:** IC / Senior IC | **Specialism:** Model development, training optimization, feature engineering

**Responsibilities:** Build and train ML models; develop feature engineering pipelines; optimize model performance; conduct model evaluation and validation; manage training infrastructure; implement experiment tracking; maintain model versions and configurations.

**Skills Required:** ML fundamentals (supervised/unsupervised learning, feature engineering); statistical analysis; programming (Python, Scala); model evaluation and debugging; cloud platforms (AWS SageMaker, Azure ML, Vertex AI).

**Career Path:** Junior ML Engineer → ML Engineer → Senior ML Engineer → ML Architect

## Prompt Engineer

**Level:** Senior IC / Specialist | **Specialism:** Prompt design, evaluation, optimization

**Responsibilities:** Design and iterate system prompts; develop prompt evaluation frameworks; optimize prompts for quality and cost; manage prompt version control; conduct A/B testing of prompts; document prompt design patterns; share learnings across teams.

**Skills Required:** Deep understanding of LLM capabilities and limitations; systematic prompt design methodologies; evaluation frameworks; cost optimization; communication skills.

**Career Path:** As a specialist: Prompt Engineer → Senior Prompt Engineer → Prompt Engineering Lead

## Context Engineer

**Level:** IC / Senior IC | **Specialism:** Context design, RAG optimization, retrieval tuning

**Responsibilities:** Design chunking strategies for knowledge documents; select and tune embedding models; optimize retrieval pipelines (hit rate, MRR, NDCG); implement hybrid retrieval strategies; design metadata schemas; conduct RAG quality evaluation.

**Skills Required:** Deep understanding of RAG architecture; embedding models and vector databases; retrieval algorithms; information retrieval metrics; programming in Python; optimization skills.

**Career Path:** Context Engineer → Senior Context Engineer → Knowledge Platform Lead

## Knowledge Engineer

**Level:** IC / Senior IC | **Specialism:** Knowledge base design, document pipelines, ontology

**Responsibilities:** Design knowledge base architecture and taxonomy; build document ingestion pipelines; maintain knowledge quality and freshness; implement PII detection and access controls; conduct knowledge base evaluations; document knowledge sourcing procedures.

**Skills Required:** Information architecture and taxonomy design; data pipeline development; knowledge graph design; ontology tools; Python/SQL programming; domain knowledge.

## LLMOps Engineer

**Level:** IC / Senior IC | **Specialism:** LLM deployment, monitoring, cost management

**Responsibilities:** Deploy and manage LLM APIs and services; implement cost tracking and optimization; develop observability and monitoring dashboards; manage LLM vendor relationships and model selection; optimize inference latency and throughput; manage model fine-tuning pipelines.

**Skills Required:** LLM APIs and platforms (Bedrock, Azure OpenAI, Vertex); observability tooling; cost optimization; Python/Go programming; cloud platforms; vendor management.

**Career Path:** LLMOps Engineer → Senior LLMOps Engineer → AI Platform Lead

## AgentOps Engineer

**Level:** IC / Senior IC | **Specialism:** Agent runtime, deployment, monitoring, safety

**Responsibilities:** Deploy and operate AI agents in production; implement agent lifecycle management; develop agent monitoring and observability; manage agent dependencies and tool integrations; troubleshoot agent failures; maintain agent fleet dashboards.

**Skills Required:** Agent frameworks and platforms (LangGraph, CrewAI, Bedrock); MCP protocol; observability and monitoring; Python/Go; incident response; agent safety principles.

**Career Path:** AgentOps Engineer → Senior AgentOps Engineer → Agent Platform Lead

## Data Scientist

**Level:** IC / Senior IC | **Specialism:** Data analysis, experimental design, statistical modelling

**Responsibilities:** Conduct exploratory data analysis; design and execute experiments; build statistical models; analyze model performance and failures; conduct bias and fairness assessments; document findings and recommendations.

**Skills Required:** Statistical analysis and hypothesis testing; programming (Python, R); data visualization; machine learning fundamentals; experimental design; domain knowledge.

## Platform Engineer (AI-focused)

**Level:** IC / Senior IC | **Specialism:** Platform architecture, infrastructure, self-service tooling

**Responsibilities:** Build and operate AI platform services; develop self-service tooling and SDKs; manage infrastructure for AI workloads; implement cost tracking and governance; ensure platform reliability and performance; drive platform adoption.

**Skills Required:** Cloud platform expertise (AWS, Azure, GCP); Kubernetes and containerization; platform design; Python/Go programming; monitoring and observability; vendor management.

---

## Career Progression

**IC Track:** Junior Engineer → Engineer → Senior Engineer → Principal Engineer

**Management Track:** Engineer → Engineering Manager → Senior Manager → Director → VP

**Specialist Track:** Engineer → Senior Engineer / Specialist → Lead (Prompt Engineering Lead, Platform Lead, etc.)
