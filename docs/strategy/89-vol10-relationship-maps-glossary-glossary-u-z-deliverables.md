# Enterprise Glossary: U-Z & Deliverables Cross-Reference

Final glossary section (U-Z) and architecture deliverables cross-reference.

## U–V

**Value Chain**: Full sequence of activities creating value from raw input to end customer (Strategy domain).

**Value Proposition**: Statement of the unique value an organization delivers to customers (Strategy domain).

**Value Stream**: End-to-end sequence of steps delivering value to a stakeholder (Architecture domain).

**Value Stream Mapping**: Visual technique mapping material and information flow in a value stream (Architecture domain).

**Vector Database**: Storage optimized for dense vector embeddings; enables semantic search (AI domain).

**Vendor Management**: Processes governing relationships with external suppliers (Governance domain).

**Vision**: Vivid, compelling description of an organization's desired future state (Strategy domain).

## W–Z

**Wardley Map**: Strategic map showing value chain vs. evolutionary stage (Strategy domain).

**Waterfall**: Sequential project delivery: requirements → design → build → test → deploy (Delivery domain).

**WSJF (Weighted Shortest Job First)**: SAFe prioritization: Cost of Delay / Job Duration (Portfolio domain).

**Zachman Framework**: Classification schema for architecture artifacts (Architecture domain).

**Zero-Shot**: Prompting an LLM with task description only; no examples (AI domain).

**Zero Trust**: Security model: never trust implicitly; always verify identity and access (Security domain).

## Standard Architecture Deliverables by Phase

Architecture programmes produce consistent deliverable types across phases:

### Strategy Phase

**Architecture Vision**: TOGAF Phase A output; high-level solution concept and stakeholder engagement (Owner: Chief Architect).

**Architecture Principles**: TOGAF Preliminary output; fundamental rules guiding architecture decisions (Owner: Architecture Board).

**Business Capability Map**: BIZBoK output; hierarchical map of organizational capabilities (Owner: Business Architect).

### Business Architecture Phase

**Business Capability Model (L1-L3)**: BIZBoK / TOGAF B output; hierarchical capability definition (Owner: Business Architect).

**Value Stream Map**: BIZBoK / Lean output; end-to-end value flow visualization (Owner: Business Architect).

**Operating Model Canvas**: Custom output; summary of organizational operating model across dimensions (Owner: Strategy + EA).

**RACI / RASCI Matrix**: Custom output; responsibility assignment for key processes (Owner: Programme Director).

### Data Architecture Phase

**Conceptual Data Model**: TOGAF C output; logical data structure (Owner: Data Architect).

**Data Domain Map**: BIZBoK / TOGAF output; data ownership by business domain (Owner: Data Architect).

**Data Governance Framework**: DAMA / Custom output; data policy and controls (Owner: CDO).

### Application Architecture Phase

**Application Portfolio Assessment**: TOGAF C output; current-state application inventory and rationalization (Owner: Enterprise Architect).

**Application Integration Map**: TOGAF C output; system integration patterns and data flows (Owner: Solution Architect).

### Technology Architecture Phase

**Technology Roadmap**: TOGAF D output; platform, infrastructure, and services evolution plan (Owner: CTO / EA).

**Platform Architecture Blueprint**: TOGAF D output; detailed platform design (Owner: Platform Architect).

### Implementation Phase

**Architecture Roadmap**: TOGAF E output; sequenced implementation plan with interdependencies (Owner: Enterprise Architect).

**Transition Architecture**: TOGAF F output; interim states during transformation (Owner: Enterprise Architect).

### Governance Phase

**Architecture Contract**: TOGAF G output; agreement between development and sponsor on compliance (Owner: Architecture Board).
